# 工作区文件编辑

在 DSH 右侧栏直接浏览并修改当前会话工作区的文本文件。

## 功能

- 在右侧栏注册「文件编辑」标签页，引导页卡片为「编辑并保存文件」；内置的只读「工作区文件」浏览页不受影响。
- 内置文件页的工具栏会多出一个铅笔按钮，可一键切到文件编辑器。
- 目录树按需展开，每次展开都会重新列目录；刷新按钮会重新读取根目录与所有已展开目录。
- 点击文件即可在标签页内编辑，`Ctrl+S`（macOS 为 `Cmd+S`）保存；保存遵循当前会话的沙箱策略与文件版本校验。
- 代码文件按扩展名自动语法高亮（JS/TS、Vue/HTML/XML、CSS/SCSS/LESS、JSON、YAML、Python、Java/Kotlin、C/C++、Go、Rust、Swift、PHP、Ruby、Lua、SQL、Shell、PowerShell、Batch、INI/TOML、Diff 等），配色沿用主题的代码色板；输入法拼写过程中临时显示纯文本，避免遮挡候选文字。
- 输入联想：输入两个字符后，在光标处弹出当前文件内的单词与该语言常用关键字；`Tab` 或 `Enter` 接受，`↑`/`↓` 选择，`Esc` 关闭，`Ctrl+Space` 手动触发（空前缀时列出高频词）。没有联想时 `Tab` 仍插入两个空格。
- 行内 AI 补全：在代码文件中停止输入约 400 ms 后，用当前 profile 的默认模型在光标处生成灰色行内建议（最多 6 行）。`Tab` 接受，`Esc` 忽略，`Ctrl+Space` 手动请求。自动补全会跳过 `.env`、密钥、凭据等敏感文件名；手动请求不受此限制。启用该功能会把光标附近约 8 KB 前缀和 4 KB 后缀（含文件路径）发送给配置的模型提供方，请注意代码隐私。
- 补全接受后可撤回：刚用 `Tab` 插入的行内补全或词补全，可立即按 `Ctrl+Z`（macOS 为 `Cmd+Z`）还原插入前的文本和光标位置；之后继续输入则恢复浏览器原生的撤销行为。
- 工作区搜索：列表页工具栏的放大镜可切换「文件」/「内容」搜索。「文件」按名称或相对路径查找工作区文件；「内容」搜索工作区文本文件并显示行号与预览。结果最多 200 条，点击结果会打开文件，内容结果会跳到对应行。
- 当前文件查找：编辑器工具栏的放大镜或 `Ctrl+F`（macOS 为 `Cmd+F`）打开查找条；`Enter` / `Shift+Enter` 切换下一个/上一个匹配，`Esc` 关闭。匹配位置会用浅色底标出并滚动到可视区域。
- 文件在编辑器之外被改动时拒绝覆盖，并给出「重新读取」操作。
- 保留文件原有的换行风格（LF / CRLF / CR）；混合换行的文件会在底栏提示。
- 未保存的草稿暂存在浏览器标签页的 `sessionStorage` 中：切换右侧栏标签、折叠侧栏、切换会话、关闭标签页或刷新页面后，重新打开同一文件会恢复草稿。
- 如果文件在存放草稿期间被外部修改，重新打开时不会静默丢弃草稿，而是提示「恢复草稿 / 丢弃草稿」；恢复旧草稿后保存会覆盖磁盘上的新内容，请自行确认。
- 有未保存修改时，刷新或关闭浏览器页面会先弹出浏览器确认框。
- 编辑器支持 Tab 缩进、Escape 让出焦点，以及 `Ctrl+S` / `Cmd+S` 保存（焦点位于编辑器面板内时）。

## 使用

1. 在右侧栏标签条点「+」，在引导页选择「编辑并保存文件」。
2. 或在文件页工具栏点铅笔按钮。
3. 或在任意会话页面按 `Ctrl+Alt+E`（macOS 为 `Cmd+Option+E`）。
4. 在文件树中点击文件开始编辑；工具栏的「保存」或 `Ctrl+S` 写入磁盘。
5. 输入两个字符后会弹出补全列表：`Tab` / `Enter` 接受选中项，`↑` / `↓` 选择，`Esc` 关闭，`Ctrl+Space` 手动打开；点击候选项也可以插入。
6. 在代码文件中停一下，光标后会出现灰色行内 AI 建议；`Tab` 接受，`Esc` 忽略，接受后可用 `Ctrl+Z` 撤回。`Ctrl+Space` 可随时请求一次行内补全。
7. 列表页工具栏的放大镜打开工作区搜索，切换「文件」/「内容」；`Ctrl+F` 在当前文件内查找。

## 限制

- 只支持 UTF-8 文本文件，单个文件最多读取 2 MB；图片、二进制和超大文件会给出提示。
- 只编辑已经存在的文件，不提供新建、删除、重命名。
- 写入范围限制在当前会话的工作区目录内。
- 保存遵循当前会话的沙箱策略：会话处于只读沙箱时无法保存，工作区写入模式下只能写入工作区。
- 编辑器只做整文件保存，不提供差异对比与行号。
- 联想来自当前文件最近约 80 KB 的标识符与当前语言的常用关键字；不扫描其他文件、不做类型或成员语义分析，也不联网。光标位于单词中间或选中文本时不弹出联想。
- 行内 AI 补全依赖当前 profile 的默认对话模型。模型不可用、超时或被取消时，自动补全静默结束，手动触发会显示原因。它只基于当前文件上下文，不做跨文件或类型分析，生成结果的质量取决于所选模型。
- 每次行内补全都是一次普通模型请求，会计入对应模型的用量；停止输入 400 ms 的停顿才触发一次，继续输入会取消尚未返回的请求。
- 自动 AI 补全会把光标附近代码发送给模型提供方；敏感文件名（`.env`、`*.pem`、`*.key`、`id_rsa`、`credentials` 等）不会自动请求，但仍可手动请求。若代码不允许离开本机，请停用该插件。
- 工作区搜索不建立索引：搜索时按目录遍历（跳过 `.git`、`node_modules`、`dist` 等目录），最多返回 200 条、最多扫描 8 秒；内容搜索只读取 512 KB 以内的 UTF-8 文件。超大工作区可能只得到部分结果或超时，可缩小搜索词后重试。
- 当前文件查找最多标记 1000 个匹配。
- 文件超过 150 KB 时不再语法高亮（仅保留纯文本编辑）；50 KB 以内逐键高亮，50–150 KB 在停止输入约 150 ms 后着色。未知扩展名的文件按纯文本显示。
- 草稿保存在浏览器标签页内，关闭整个浏览器标签页后不会保留；切换右侧栏标签、折叠侧栏或切换会话时保留。
- 混合换行的文件保存后会统一为占多数的换行风格。
- 仅 Web 客户端提供该标签页；编辑器内容不写入会话日志。

## 关闭插件

在设置 → 插件中停用「工作区文件编辑」。停用后标签页、引导卡片、文件页按钮和快捷键一并移除；不会留下任何文件或会话数据。
